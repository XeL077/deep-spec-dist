# Deep Spec — дистрибутив

Готовое расширение **Deep Spec** для VS Code / Cursor.  
В этом репозитории только установочный пакет (`.vsix`), **без исходного кода**.

## Установка

1. Скачайте файл `deep-spec-0.0.3.vsix` из этого репозитория.
2. Откройте Cursor или VS Code.
3. `Ctrl+Shift+P` → **Extensions: Install from VSIX...**
4. Выберите скачанный `.vsix`.
5. При необходимости перезагрузите окно редактора.

### Через командную строку

```bash
# Cursor
cursor --install-extension deep-spec-0.0.3.vsix

# VS Code
code --install-extension deep-spec-0.0.3.vsix
```

## Совместимость

- Cursor (рекомендуется)
- VS Code 1.85.0+

## Что это

Deep Spec — расширение для работы со спецификацией рядом с кодом: проверка документов, контекст для агента, сборка и сверка с критериями приёмки.
